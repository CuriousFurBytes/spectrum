Spectrum System

A high-energy theme for products, docs, and IDEs inspired by Dracula and Monokai Pro. Dark and light modes reuse the same hex palette in opposition, while accent families provide expressive variants for UI emphasis.

Implementation Guidance

  • Web apps: map base tokens to page/layout surfaces and accent tokens to links, focus rings, and CTAs.
  • VS Code / IDEs: set editor background from --bg-color, foreground from --text-color, and syntax operators from accent 500/600.
  • Data viz: use blue/teal/orange/red accent families as categorical series while keeping semantic colors for alerts only.
