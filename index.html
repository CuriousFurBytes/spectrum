Spectrum Design System

Spectrum is a vibrant, high-contrast palette for UI and editor theming. Every color token is reusable across web surfaces, VS Code themes, docs, dashboards, and brand systems. Light and dark modes mirror the same exact hex values in opposite semantic roles.

Typography

Readable Contrast

Monaspace Argon is the preferred face. Base text and muted text are tuned to remain readable on both theme backgrounds. Body copy should use base text and helper copy uses muted text.
