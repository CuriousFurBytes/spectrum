Spectrum DesignSystem

Built for intense contrast, rich visual energy, and practical implementation. Spectrum keeps a shared hex palette across light and dark mode by inverting role assignments, so your brand color DNA stays stable while UI mood adapts.

Typeface: Monaspace Argon with monospaced fallbacks for consistent dev-tool and interface aesthetics.

AccentFamilies

Each family includes one base accent, 3 darker variants, and 3 lighter variants.

Purple · #7F77DD

Original accent for navigation, links, active state highlights, and syntax punctuation in IDE themes.

Red · #DE4667

Energetic action accent for urgency, launch indicators, and attention-priority badges.

Blue · #2D89EA

Technical accent for informational emphasis, links, and data-focused components.

Orange · #D85A30

High-energy accent for call-to-action clusters and spotlight modules.

Teal · #1D9E75

Balanced accent for confirmation-like emphasis without using semantic success green.

WarningChannels

Semantic tones are intentionally separate from accent families to avoid message ambiguity.

Error · #D91A47 Warning · #CA7600 Success · #188D41

UsageGuidance

  • Web apps: use accent-primary for interaction cues and links.
  • VS Code/IDE: map accent-primary to keywords; use accent-soft for line highlights.
  • Dashboards: reserve semantic colors for state and alerts only.
