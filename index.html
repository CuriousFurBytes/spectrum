Spectrum Design System

Vibrant Adaptive Color Language

Spectrum is a high-energy design palette inspired by Dracula and Monokai Pro: deep cosmic neutrals, expressive accents, and semantic status colors tuned for readability across interfaces, docs, and IDEs.

Base Foundation Colors

These are the structural tokens. Light and dark themes use identical hex values in opposition, preserving brand identity and contrast.

Background / Text Opposite--neutral-000

Dark cosmic anchor for dark mode background and light mode text.

Surface 2--neutral-100

Primary container background for cards and code panes in dark mode.

Surface 3--neutral-200

Elevated layer and separators where more depth is required.

Text / Background Opposite--neutral-900

Bright readable text in dark mode and clean page background in light mode.

Accent Families and Variants

Each accent includes one primary value with three darker and three lighter variants for borders, states, and gradients.

Purple Core Accent

Default energy tone; ideal for CTAs, links, selected tabs, and syntax highlights.

Red Accent

Use for intense focus states or campaign branding, not semantic error messaging.

Blue Accent

Calm technical emphasis for information highlights, docs links, and shell prompts.

Orange Accent

Warm urgency without crossing into warning semantics; great for badges and counters.

Teal Accent

Balanced innovation tone for success-adjacent interactions and feature spotlights.

Standard Semantic Colors

Semantic colors are intentionally distinct from accent families to avoid ambiguity in alerts and system feedback.

Error

Use for destructive outcomes, failed validation, and fatal status messages.

Warning

Use for recoverable issues, degraded service, or requires-attention notices.

Success

Use for completed actions, healthy status, and positive notifications.

Practical Interface Showcase

Primary Call To Action

Gradient buttons should pull from accent darker/lighter pair for depth.

Editor Theme Usage

Map strings to orange variants, keywords to accent-primary, and comments to neutral-300.
