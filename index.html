Spectrum

Spectrum is a compact palette for editorial interfaces, product dashboards, and code editors. It pairs a warm monochrome base with precise accent scales that can carry brand, state, and syntax without washing out the workspace.

Base
Black anchors dark UI, white anchors light UI, and the middle six shades handle elevation, dividers, text hierarchy, and disabled states.
Accent
Blue, purple, green, red, and yellow each include dark, primary, mid, soft, and faint options for interaction design.
Format
Every swatch includes copy buttons for HEX, RGB, and OKLCH values, plus matching CSS variables in spectrum.css.

Typography Rhythm

Spectrum treats color as interface grammar. Monaspace Argon gives prose, code, and labels the same engineered voice.

Headings split between base foreground and the active accent, while paragraphs stay in muted base tones for steady reading.

Applied Usage

Spectrum works best when the base scale does the structural work and accent colors carry meaning. Reserve the strongest accents for decisions, states, and orientation.

Web Apps

Use base white/black as the page pair, middle base shades for borders and surfaces, and the chosen accent for primary actions.

  • Primary buttons: --accent-control
  • Links and display text: --accent-display
  • Cards and panels: --color-surface

VS Code IDE

Map the base scale to the editor shell, then assign accent families to syntax and status states.

  • editor.background: --base-black
  • editor.foreground: --base-white
  • activityBar.activeBorder: active accent primary

Data Products

Blue should handle neutral information, green success, red risk, yellow attention, and purple special or creative categories.

  • Use shade 3 for categorical marks.
  • Use shade 5 or 6 for background fills.
  • Use shade 1 or 2 for labels on light charts.

Docs Sites

Keep paragraphs neutral and use faint accent panels for notes, warnings, success messages, and code annotations.

  • Information notes: blue frost or haze.
  • Warnings: yellow frost or cream.
  • Errors: red frost with ruby text.

Token Map

Use raw variables when you need a specific palette value. Use semantic variables when the interface should follow the selected theme mode and accent.

Page background --color-background Base white in light mode, base black in dark mode.
Primary foreground --color-foreground Base black in light mode, base white in dark mode.
Surface --color-surface The default card, panel, and input background.
Accent primary --accent-primary The exact primary from the selected accent family.
Accent display --accent-display A readable accent for headings and links in the current mode.
Accent control --accent-control The chosen accent tuned for buttons, toggles, and focus states.
